Coomi Beta 0.9.9-rc30：把这一轮真机反馈的问题按根因改完了（消息状态 + 窗口/DPI + 卡顿 + 安装 + 插件页面 + 自动更新）。

一、生成中突然「变回发送键 / 思考中消失」（根因修复）
· 引擎对任何命令失败都回 error 帧（含连上后自动下发的偏好设置），前端以前收到就整轮收成 idle —— 现在命令级错误只提示，不再动这一轮的流式状态；只有「没配模型」这类致命错误才收尾
· 心跳与 session_state 以前用本地缓存的会话列表判「还在不在跑」，而这份缓存停在发送之前；现在统一走同一条硬判据（引擎最新 running + 非工具执行中 + 不在工具豁免窗口）
· 会话列表里查不到当前会话时按「未知」处理（继续等待），不再当成「已经跑完」
· 新增「谁把这一轮收尾了」诊断流水（CDP: __sessionDebug.settleLog()），下次再有类似现象能直接看到触发者

二、窗口与「运行环境」展开超出屏幕（DPI>100% 错位）
· 窗口尺寸改为按显示器工作区折算（不再写死 1180×780）：125%/150% 缩放下窗口不会再比屏幕还高，底部输入框与浮层不再跑到屏幕外，并加了最大尺寸上限
· 技能中心「运行环境」展开区现在自己滚动（最高 48vh / 420px），不再被裁掉或顶出可视区
· 界面「字号」选大/特大时，按钮、输入框、下拉框的高度跟着一起放大，不再文字贴边被裁

三、切页与流式更顺
· 切页保活最近 4 个页面（原来只保 2 个）：来回切不再每次冷挂载
· 技能中心等页面加了 60 秒数据保鲜期：切回来不再重新打三张网络、重渲染整张列表
· 流式吸底滚动改为「每帧最多写一次 scrollTop」：正文越长越顺（浏览器不再被同一帧里的多次布局拖住）
· 省电档下状态动画改用 CSS 点阵（不再常驻 canvas 重绘）

四、消息排版
· 修复「工具卡片与正文之间忽有忽无的空行」：流式纯文本按字面渲染模型输出的空行，而轮结束走 Markdown 又把它折叠掉 —— 现在统一在渲染前折叠首部空行

五、安装：有任务、有进度、有日志
· 工具/技能安装改为引擎任务中心里的正规任务（立刻返回任务号，后台下载解压），卡片上能看到进度与日志尾部，「任务」页签里能看到状态与完整输出
· 任务中心不再残留「永远运行中」的幽灵记录（排队轮次复用同一条记录），任务标题也有了中文名

六、多会话并行可见
· 会话列表每 5 秒同步一次引擎的权威运行状态：另一个会话在后台跑时，列表上的运行指示与任务页签都会跟着亮起来，点「跳到会话」即可切过去（引擎本来就是并行执行，以前只是界面看不见）

七、插件可以注册页面了（v2.1，新）
· plugin.json 新增 views 声明：启用后左侧导航栏多出一个入口，点开就是插件自己的页面（插件目录内的 .html）
· 页面跑在独立沙箱 iframe 里（不给主界面 DOM、localStorage 与 IPC）；需要数据时通过 postMessage 让宿主代发只读 /api/ 接口
· 停用或卸载插件，入口立即撤销；帮助中心「插件系统」一节已补完整用法

八、更新可以一键完成了（新）
· 「设置 → 关于」新增「一键更新」：下载 → sha256 校验 → 静默安装 → 自动重启
· 下载会走你在设置里选的 GitHub 镜像（国内直连 raw 常断），并支持清单里的多镜像地址依次重试；浏览器手动下载仍保留为兜底
· 更新说明不再永远是「服务端未提供」：清单里补上了 changelog
