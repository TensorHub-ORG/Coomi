# 功能地图

界面一共四块主页面 + 一条右栏。每一块只干一件事，找功能时先想「它属于哪一块」。

## 对话（左侧导航第一项）

真正干活的地方：一句话下去，AI 会自己拆步骤、调工具、读写文件。

- 消息列表：正文、工具调用、产物卡片、审批卡片都在这里；
- 输入区：附件、引用、队列中的插话都显示在输入框上方；
- 顶部工具栏：会话标题、搜索（Ctrl/Cmd + F）、导出与会话操作；
- 右侧消息导航条：长对话里点刻度跳转（Ctrl/Cmd + ↑ / ↓ 也可）。

## 技能中心

给 AI 加能力的地方，两类东西：

- **技能（Skill）**：一套做事的方法与规范，装完就能在对话里使唤；
- **MCP 服务**：外部工具/数据源接入，装完 AI 多一批可调用的工具。

顶部两条状态：**运行环境**（缺什么运行时就提示装）、**已安装**（可禁用、可回滚到上一个备份版本）。

## 产物中心

AI 写出来的文件都汇总在这里：按会话列出，支持预览（文本、代码、图片、PDF、Word、表格、压缩包等）、另存为、在文件夹中打开。

预览用的沙箱不联网、不读取本机其它文件，只是把内容画出来。

## 设置

八个分组，最重要的是前四个：

| 分组 | 管什么 |
| --- | --- |
| 通用 | 主题、字号、密度、动效、安全模式、运行中插话方式、崩溃后恢复方式 |
| 外观 | 消息栏宽度、字体、精简/省电档 |
| 模型与厂商 | Provider 与模型的增删改、激活、上下文窗口、参数覆盖 |
| 工作区 | 默认工作目录、最近使用过的目录 |
| AI 能力 | 长期记忆、上下文压缩阈值、子代理与思考强度 |
| 数字生命体 | 常驻伙伴人格、主动打扰节奏、羁绊与日志 |
| 引擎与诊断 | 运行状态、重启/停止、日志、镜像与存储、备份与清理、开发者面板 |
| 关于 | 版本、制作人、开源说明、检查更新 |

## 右栏（Ctrl/Cmd + B 开合）

- **产物**：当前会话的产物列表；
- **预览**：跟随对话里最新的富内容（可固定）；
- **文件**：工作目录浏览器；
- **用量**：本轮与累计 token；
- **上下文**：窗口占用、距压缩阈值、压缩历史（可手动压缩）；
- **任务**：子代理与后台任务的状态。

## 命令面板（Ctrl/Cmd + K）

记不住入口就用它：搜页面名、会话、动作，回车直达。
