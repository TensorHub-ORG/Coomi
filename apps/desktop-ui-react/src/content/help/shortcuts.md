# 快捷键表

修饰键统一写 **Ctrl/Cmd**：Windows 上是 Ctrl，macOS 上是 Cmd。

## 全局

| 快捷键 | 作用 |
| --- | --- |
| Ctrl/Cmd + K | 打开 / 关闭命令面板 |
| Ctrl/Cmd + N | 新建对话 |
| Ctrl/Cmd + B | 收起 / 展开右侧栏 |
| Esc | 关闭当前浮层（命令面板、抽屉、搜索条、预览） |

## 对话页

| 快捷键 | 作用 |
| --- | --- |
| Enter | 发送 |
| Shift + Enter | 换行 |
| Ctrl/Cmd + F | 会话内搜索（Enter 下一个，Shift + Enter 上一个，Esc 关闭） |
| Ctrl/Cmd + ↑ / ↓ | 沿右侧消息导航条跳到上一个 / 下一个刻度 |
| End | 一键滚到底部（生成过程中同样有效） |
| Esc（输入框里） | 清空已引用的消息 |
| Backspace（输入框为空时） | 删掉最后一条引用 |

## 浮层与表单

| 快捷键 | 作用 |
| --- | --- |
| ↑ / ↓ | 命令面板里上下选择 |
| Enter | 执行选中的命令 / 提交单行输入 |
| → | 命令面板里进入分组 |
| ← 或 Backspace（输入为空时） | 返回上一层分组 |
| Ctrl/Cmd + Enter | 多行输入框提交 |
| Esc | 取消当前编辑或关闭浮层 |

## 鼠标

| 操作 | 作用 |
| --- | --- |
| 拖文件到输入框 | 加为附件 |
| 划选消息正文 | 弹出引用浮条 |
| 拖动面板之间的分隔线 | 调整会话列表 / 右栏宽度（双击复位） |
| 拖标题栏 | 移动窗口（双击最大化） |
