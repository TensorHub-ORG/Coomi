# 隐私与数据摘要

一句话：**本地优先**。会话、记忆、密钥、产物都在你自己的机器上，出网的东西只有两处——你配置的模型服务，和你主动触发的技能/资源下载。

## 存在哪里

一切都在本机数据目录 `%APPDATA%\Coomi`：

| 位置 | 内容 | 敏感度 |
| --- | --- | --- |
| `config\providers.json` | Provider 地址、模型、API Key | **高**：别提交、别分享 |
| `config\settings.json`、`web-settings.json` | 引擎设置、镜像、遥测开关 | 中 |
| `sessions` | 会话与消息全文 | **高**：可能含你贴进去的资料 |
| `memory\agent-memory.jsonl` | 长期记忆条目 | 中 |
| `skills` / `mcp` / `tasks` / `usage` | 技能与服务、任务记录、用量统计 | 低 |
| `engine.log`、`crash_rust.log`、`metrics.jsonl` | 运行日志与指标 | 低（排查问题用） |

## 什么会出网

| 场景 | 发到哪 | 发什么 |
| --- | --- | --- |
| 对话 | 你激活的那个模型服务商 | 本轮要发给模型的上下文（含历史消息、附件、工具结果） |
| 技能 / MCP 安装 | 技能市场与对应源 | 安装请求本身；不会带上你的会话内容 |
| 检查更新 | 版本清单 `github.com/TensorHub-ORG/Coomi` | 只读一次版本信息，不上传任何本地数据 |
| 运行环境安装 | 系统包管理器（winget / uv 等） | 包名 |
| 本地模型 | 不出网（除非你手动下载模型） | — |

界面本身不接入任何第三方统计脚本；遥测是否有内容上报，以「引擎与诊断」里的遥测开关为准——关掉它就不会有任何使用数据离开本机。

## 你的控制权

- **密钥**：只存本机；已保存的 Key 在界面上默认不显示，需要时手动点「显示」；
- **记忆**：四个开关随时可关（长期记忆 / 记忆写入 / 自动注入 / 向量检索），条目文件可自行删除；
- **上下文**：随时手动压缩，或新建会话重新开始；
- **清理**：清理缓存不动会话与配置；
- **备份**：备份目录里包含密钥与会话全文，存放位置自己挑，别放共享盘。

## Beta 阶段提醒

当前是 Beta 测试版，数据格式仍可能调整。重要内容请定期用「创建备份」留一份，并避免把数据目录直接放进同步盘（同步冲突会同时破坏会话与配置）。
