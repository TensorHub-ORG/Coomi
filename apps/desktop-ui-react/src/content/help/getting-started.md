# 快速上手

四步就能跑完一圈：**配置模型 → 新建对话 → 装技能 → 看产物**。整个流程不需要联网注册，模型由你自己接入。

## 1. 配置模型（第一次启动只需要做一次）

1. 左侧导航点「设置」→ 左列选「模型与厂商」；
2. 点「新增」，填三件事：**名称**（随便起）、**Base URL**（服务商给的接口地址，注意大多要带 `/v1`）、**API Key**；
3. 保存后点一次「获取模型」（会向上游拉一次可用模型列表），再选一个模型；
4. 点「激活」——被激活的那一条才是当前对话实际使用的模型。

> 密钥只写在**本机**的数据目录里（`%APPDATA%\Coomi\config\providers.json`），不会上传到任何服务器。
> 想用本地模型（不联网、不花 token）就去「设置 → 本地模型」，下载并启动后同样在这里激活。

## 2. 新建对话

- 按 **Ctrl/Cmd + N**，或点左侧导航「对话」再点列表顶部的「新建」；
- 输入框里直接说话即可；**Enter 发送、Shift + Enter 换行**；
- 对话的工作目录（AI 读写文件的根）在会话创建时确定，默认是 `%USERPROFILE%\Coomi`，可以在「设置 → 工作区」里改默认值。

对话里可以随时：拖文件进输入框＝加附件、划选消息＝引用、生成中继续发消息＝插话（排队或打断，见「设置 → 通用」）。

## 3. 装技能

1. 左侧导航点「技能中心」；
2. 先看页面顶部的**运行环境**状态条——缺 Node / uv 之类的运行时会挡住一部分技能，按提示点「安装」即可；
3. 在列表或搜索框里找到想要的技能，点「安装」；装完如果动过运行环境，**必须点「重启应用」**（PATH 变了只有新进程才认）。

技能＝一段告诉 AI「这类活该怎么干」的说明书，装完在对话里直接用自然语言提要求就行。

## 4. 看产物

- **产物中心**（左侧导航）：当前会话产出的文件，可以预览、另存为、在文件夹中打开；
- **右侧栏**（Ctrl/Cmd + B 开合）：产物 / 预览 / 文件 / 用量 / 上下文 / 任务 六个页签，跑长任务时最有用的就是「任务」和「上下文」。
