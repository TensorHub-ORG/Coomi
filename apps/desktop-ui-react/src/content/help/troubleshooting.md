# 故障排查

## 日志在哪？

| 文件 | 位置 | 看什么 |
| --- | --- | --- |
| 引擎运行日志 | `%APPDATA%\Coomi\engine.log` | 启动失败、端口、锁文件、运行时安装等 |
| 引擎崩溃日志 | `%APPDATA%\Coomi\crash_rust.log` | 崩溃时的最后现场 |
| 引擎指标 | `%APPDATA%\Coomi\metrics.jsonl` | 逐行 JSON 的运行指标 |

界面上最快的一条路：设置 → 引擎与诊断 → 「运行日志」→「打开」；也可以用「引擎日志」对话框直接看末尾若干行。

排查任何问题前先看**运行状态**那一行：运行中（带端口）/ 启动中 / 已停止 / 异常（带原因），状态不同处理方式完全不同。

## 安全模式（界面卡住时的自救开关）

设置 → 通用 → **安全模式**。打开后：动效、富内容预览、语法高亮、长列表虚拟化全部让路，只画纯文本——界面会变得朴素但一定能动。

- 什么时候用：滚动卡顿、预览打不开、一进某页面就卡死；
- 还有两条备用入口：启动时在地址里加 `?safe=1`，或让界面自己判定（1 秒内提交次数超阈值会自动切进安全模式并提示一次）；
- 排查完记得关掉它，否则会一直停留在精简观感。

## 备份与恢复

**备份**：设置 → 引擎与诊断 → 「维护」→「创建备份」。备份会跳过运行时与缓存目录（`runtime-v2`、`node_modules`、`target` 这类），只搬真正属于你的数据。

要备份的东西（都在 `%APPDATA%\Coomi`）：

| 目录 / 文件 | 内容 |
| --- | --- |
| `sessions` | 会话与消息 |
| `memory` | 长期记忆 |
| `config` | Provider（含密钥）、设置、技能与 MCP 配置 |
| `skills` / `mcp` | 已安装的技能与服务 |
| `tasks` | 后台任务记录 |
| `desktop-ui.json` | 壳的界面偏好（主题、关闭行为） |

**恢复**：先退出应用（托盘 →「退出」），用备份覆盖回数据目录，再启动。恢复后如果界面显示引擎异常，按「引擎断开怎么办」那三步走一遍即可。

**只清理不恢复**：设置 → 引擎与诊断 → 「清理缓存」只会删缓存，不动会话与配置。

## 其它常见症状

| 症状 | 先试这个 |
| --- | --- |
| 应用打不开 / 白屏 | 安全模式启动（`?safe=1`）；再看 `crash_rust.log` |
| 引擎反复重启 | 看 `engine.log` 末几行；确认没有多个 `coomi.exe` 抢同一个数据目录 |
| 装了技能但 AI 不会用 | 「重启应用」让 PATH 刷新；技能中心里确认该技能是「已启用」 |
| 预览打不开某个文件 | 文件过大或类型不支持；关掉安全模式再试，或用「在文件夹中打开」用本机程序看 |
| 想确认引擎自身健康 | 设置 → 引擎与诊断 → 开发者面板里的健康检查信息 |
