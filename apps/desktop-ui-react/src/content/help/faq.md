# 常见问题

## 引擎断开怎么办？

「引擎已断开」＝壳托管的后台进程 `coomi.exe` 掉了或者被别的进程挤掉了。按顺序处理：

1. **先清干净**：托盘图标右键 →「退出」，然后在任务管理器里确认没有残留的 `coomi.exe`；
2. **删锁文件**：删掉 `%APPDATA%\Coomi\engine.lock`（引擎同一时间只允许一个实例，异常退出会留下锁文件挡住新进程）；
3. **看日志**：设置 → 引擎与诊断 → 「运行日志」→「打开」，看 `%APPDATA%\Coomi\engine.log` 的末尾几行，失败原因基本都在那里；
4. 重新打开应用。壳在拉起引擎前会先清场，多数情况第 1 步做完就好了。

> 引擎自己也会清理过期锁（日志里会有 `removing stale lock`），所以锁文件不是每次都必须手删——先看日志再说。

## 模型报错怎么看？

| 现象 | 多半是 |
| --- | --- |
| 401 / 403 | API Key 错了、过期了，或没在该 Provider 后台开通这个模型 |
| 404 | Base URL 少了 `/v1` 之类的路径段，或模型名和上游不一致（回设置里点一次「获取模型」） |
| 429 | 上游限流：等一会儿，或换模型/换厂商 |
| 上下文超长 | 换窗口更大的模型，或把「上下文压缩」调积极一点（设置 → AI 能力） |
| 连接失败 / 超时 | 本机网络或代理问题；可在「引擎与诊断 → 镜像」里测一次连通性 |

改完 Provider 记得点一次「激活」——设置里改的是配置，激活的才是当前生效的那一条。

## 技能装不上，说缺运行环境

技能中心顶部有「运行环境」状态条，缺什么会直接列出来：点对应的「安装」按钮即可（引擎会调用本机已有的包管理器，例如 winget / uv）。

装完**必须点「重启应用」**：安装运行环境改的是 PATH 环境变量，只有新启动的进程才读得到。重启后再回到技能中心，状态条会重新检测。

## 任务卡住 / 中断 / 插话排队有什么区别？

- **卡住**：先看右栏「任务」页签和「引擎与诊断」的运行状态。任务真的不动了，用「停止」结束这一轮；引擎进程本身没响应就「重启引擎」（当前会话会自动恢复）；
- **中断**：设置 → 通用 →「运行中插话」选**打断**——你新发的消息会取消当前这一轮并立刻重新开始，已经生成的内容会保留成一条助手消息；
- **排队**（默认）：你新发的消息排在当前轮后面，本轮跑完立刻按顺序执行，已生成内容一个字都不丢。

长任务期间点窗口关闭按钮＝隐藏到托盘，任务继续跑（可在设置里改成直接退出）。

## 上下文什么时候压缩？阈值怎么调？

上下文＝这一轮真正发给模型的对话历史，有窗口上限。接近上限时引擎会自动压缩：把较早的内容压成摘要。

- **触发条件（满足其一）**：窗口占用超过触发比例、总量超过绝对下限、或消息条数超过上限；
- **压完留多少**：保留区内的最近原文不参与压缩；
- **在哪里调**：设置 → AI 能力 → 上下文压缩。三档预设：保守（90% · 20 万 · 条数关）、平衡（默认，85% · 10 万 · 200 条）、积极（75% · 5 万 · 80 条），也可以单项自定义；
- **手动压一次**：在对话里发送 `/compact`，或在右栏「上下文」页签里点压缩；
- **想看实际发生了几次**：右栏「上下文」页签里有压缩历史（时间、原因、压缩前后 token）。

## 记忆是什么？怎么清？

**长期记忆**＝跨会话保留的事实与偏好（例如「我在用 Windows」「项目在 G 盘」）。开启时，相关的内容会在合适的时候自动注入到当前对话里。

开关在设置 → AI 能力：

- **长期记忆**：总开关，关掉就完全不参与；
- **记忆写入**：关掉后只读不写，不再记录新的记忆；
- **自动注入**：关掉后 AI 仍可主动检索记忆，只是不自动塞进上下文；
- **向量检索**：关掉后退回关键词匹配。

记忆条目以文件形式存在本机（`%APPDATA%\Coomi\memory\agent-memory.jsonl`）。要清空：先退出应用，再删除该文件里的对应条目或整个文件（删整个文件＝清空全部记忆，会话记录不受影响）。

只想让**当前对话**忘掉旧内容，用「压缩」或新建一个会话即可，不必动记忆。
