首页艺术字来自用户提供的 `Coomi.png` 与 `慎终如始则无败事.png`。

原图为白底黑字，已去除白底、按笔画边界裁切，并保留抗锯齿透明度：

- `coomi-wordmark.png`：英文笔画，455 × 157。
- `coomi-dot.png`：同尺寸的句点蒙版，与英文笔画对齐。
- `coomi-motto.png`：书法标语，1702 × 190。

CSS 蒙版使用应用的正文色与品牌蓝，因此明暗主题均无白色底框；页面仍提供可访问的文字。首页英文艺术字最大宽度 104px，前置 Coomi 图标 48px，标语最大宽度 420px，窄窗口按比例缩放。

首页默认使用国风。在「设置 → 外观 → 初始会话界面标语字体」选择「国风」后，Coomi. 与标语同步使用艺术字蒙版；选择「默认」时两者同步显示无衬线文字。选择保存在 `coomi.prefs.v2` 的 `welcomeSloganFont` 字段。
