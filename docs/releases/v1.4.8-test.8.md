# v1.4.8-test.8 更新说明【测试】

版本码：74；平台：Android 7.0+；架构：arm64-v8a。

- 小窗卡片中的辅助会话采用更紧凑的自适应排版，统一缩放消息、思考过程、工具卡片、附件与操作按钮，在有限空间中显示更多内容。
- “启动首页”新增“新会话快捷指令”管理：可配置四条快捷指令的图标、名称和内容，支持保存多套方案、随时切换，以及一键恢复默认方案。
- 优化“外观”设置的显示比例界面，主题和比例控件会按手机可视高度紧凑排列，无需滚动即可完成设置。
- 输入框中的文本与附件改用同一个限高滚动区域；长文本、多个文件和图片缩略图混合输入时不再持续撑高输入框。
- 修复长会话压缩后的上下文顺序错误。最近完整回合始终按照“用户消息—助手回复—工具结果”的原始顺序发送给模型，避免同一会话中遗忘上一轮回复。

验证范围：Rust 上下文压缩单元测试、Web 前端回归测试与类型检查、Web 生产构建、Android 资源处理与 Java 编译、Android release 构建及 APK 内置资源校验。
