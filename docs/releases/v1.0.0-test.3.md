# v1.0.0-test.3 发布说明【测试】

- Deck 模式：新增 Work / Deck 模式切换、任务侧栏和多 CLI 终端面板；Deck 对话复用 Work 的 Agent、权限审批与消息交互能力。
- CLI 调度：加入 Coomi 内置 CLI 操作 Skill，按终端识别、读取、派发、等待和验收的流程控制 Codex / ZCode，减少重复授权和无效状态轮询。
- 终端控制：改进持续接管、用户释放与 CLI 问询处理，支持安装 CLI、配置 Coomi 内部模型提供方，并显示可复制的终端编号。
- 终端显示：归一化 Agent 读取的 CLI 文本，将终端状态与 CLI 输出分开；支持停止/关闭、主题切换、自适应重绘以及调度记录收起、半屏和全屏。
- 对话体验：Deck 延续 Work 的工具审批、问询和消息操作，并修复输入区、消息流及窗口布局问题。

本版本为测试版，欢迎反馈使用问题。
