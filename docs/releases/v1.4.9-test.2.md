# v1.4.9-test.2 更新说明【测试】

基于 Comax 1.5.1o2 底座继续开发，保留底层优化，补齐 Coomi 1.4.8 的功能与移动端交互。

- 修复会话最右侧的宽阴影：关闭的产物抽屉不再向页面内投射阴影，保留正常滚动条；恢复 1.4.8 的浅色表面与轻量层次，不再全局禁用卡片阴影。
- 统一手机返回键、系统返回手势与左上角返回。提供商详情返回列表；从会话进入设置、AI 工作室、协同工作台等功能后返回原会话；从控制台进入则返回控制台，并保留未保存配置的确认流程。
- 设置继续按“对话 / 连接与模型 / 应用”划分模块，补齐提示词库、新会话快捷指令和用户体验改进计划入口；返回设置保留模块与滚动位置，返回会话保留草稿与浏览位置。
- 接通 1.4.8 的新会话快捷指令：待机页显示当前方案的四条指令，支持编辑图标、名称和内容，保存切换多套方案与恢复默认；“启动首页”中的配置跨引擎端口持久保存。
- 保留 1.4.8 的上下文三层扇形工具中心与提示词、辅助会话、Git、还原、运维、数据、任务、记忆、文件和小窗功能；补齐按已保存配置运行的自动快照，手机返回先收起工具卡片，再收起扇形带。
- 保留 1.4.8 的推理强度粒子效果；发送改为从按钮中心透明水波纹发散，不再使用飞行水滴、外侧绕圈或拖尾，不影响消息立即发送，并适配减弱动效设置。
- 会话侧栏历史条目更紧凑，同时保留触控区域；控制台的“提示词库”归入“会话与体验”。
- 恢复用户体验改进计划，移除会话页自动邀请及其开关；只能通过设置或控制台主动进入，仍由用户选择加入、退出与上传授权；恢复已有画像且启用自动更新时的每周更新检查。
- 修复流式工具调用兼容性：函数名称缺失且调用信息包装在 arguments 中时，正确恢复函数名并提取真正的参数对象；支持嵌套 function 与字符串参数，非法数组参数仍拒绝执行。

本版本仅在测试通道提供，不替换正式版下载；无障碍控制模式、上下文压缩、多 API Key 轮换及当前运行环境继续沿用 1.5.1o2 底座。
