# v1.4.8 更新说明【稳定】

- **会话连续性与流式稳定性**：修复长会话压缩后消息顺序错乱造成的“忘记上一轮”问题；稳定思考过程、问题反馈、工具调用和正文的瀑布流更新，解决展开困难、结束状态错误与反复闪烁。
- **上下文快捷工具中心**：上下文用量圆环整合三层扇形工具区，可直接打开版本管理、提示词、用量、任务中心、辅助会话、记忆、隔离文件管理和小窗；优化扇形对齐、选中轮廓、动效、卡片缺口与滚动布局。
- **提示词与新会话指令**：常用提示词支持分类、搜索、编辑和一键填入；“启动首页”新增四条新会话快捷指令管理，可自定义图标、名称和内容，保存并切换多套方案或一键重置。
- **辅助会话与任务管理**：辅助会话作为主会话的独立子会话运行并归档，可在小窗卡片中继续完整 Agent 工作；紧凑自适应消息、思考、工具和附件布局。任务详情改为在选中条目下方展开。
- **版本、运维与数据工具**：重做 Git、还原、运维诊断和数据工具界面，统一 Coomi 视觉与极简 Git 线稿图标；合并社区改进并完善快照、分支、历史、同步、诊断和用量查看流程。
- **内置运行环境可靠性**：核心引擎、终端引导、Proot 与 Ubuntu 24.04 ARM64 环境随 APK 内置；完善冷启动、升级、环境校验、自修复、DNS 和安装中断恢复，减少额外下载与安装失败。
- **提供商兼容性**：完善 OpenCode 多协议模型路由；修复 DeepSeek 账号登录和智谱配置入口，并对可能引发账号异常或套餐消耗的登录方式显示明确提醒。
- **附件与输入框体验**：附件使用文件标签展示，图片提供缩略图；文本和附件共享同一个限高滚动区，长文本或多个文件不再撑高输入框，底部按钮保持单行自适应。
- **外观与移动端布局**：新增 75%–110% 软件显示比例且不缩放系统状态栏，比例控件可在手机单屏完成设置；统一消息操作栏、主题色、提示词页、侧栏、待机页和工具卡片的间距与响应式布局。
