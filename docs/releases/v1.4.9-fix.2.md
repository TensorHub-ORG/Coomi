# v1.4.9-fix.2 更新说明【稳定】

2026-10-09 发布 · Android 7.0+ · ARM64

- 控制模式悬浮窗重构为全宽窄条带：收起后不再遮挡目标应用，执行状态直接显示在条带上；配色完整跟随应用主题（含自定义配色与暗色模式），主题切换、屏幕旋转时实时刷新。
- 控制模式不再强制要求无障碍权限：仅开启悬浮窗即可启动进度条带；悬浮窗被系统关闭时自动同步退出控制模式状态。
- 输入模式键简化为「普通 / 超载」一键切换；未配置超载模型时弹出引导卡片并可一键直达设置，「狂暴模型」设置更名为「超载模型」。
- 模式面板改为带背景的浮层卡片并支持系统返回键关闭；协同任务创建面板改为固定底部的滚动表单，不再被键盘顶起。
- AI 工作室生命周期修复：重写发送、停止与切换工作室的流控制，离开页面或切换会话时立即中止旧事件流，修复旧任务事件串扰新会话、状态残留的问题。
- 工作室停止立即生效：终止流式输出、运行中的工具卡标记为「已停止」、成员状态复位，服务端优雅取消任务；同一工作室任务运行期间重复发送会得到明确提示而非叠加执行。
- 工作室工具授权按工作室隔离，修复不同工作室之间授权请求互相误吞的问题。
- 工作室 @提及支持加粗等格式并要求完整词匹配，@Anna 不会再误触 Ann、邮箱地址不再被识别为提及；成员最终回复统一收敛为一段精炼纯文本（保留 @成员 交接）。
- Shell 工具超时或取消时终止整个进程组（含衍生子进程），Android 与 Windows 均适配；新增按会话终止自有工具进程，不影响其他会话与工作室任务。
- 新增「初始会话界面标语字体」外观设置（默认 / 国风书法艺术字），原生外观页与 Web 外观页均可切换；恢复默认外观时一并重置显示比例与标语字体。
- 工具卡片展开状态跨重渲染保持；连续工具组执行与完成后默认收起，手动展开后尊重用户选择；审批风险条仅在卡片展开时显示。
- 聊天页模式面板展开时隐藏状态栏避免遮挡；工作室用户消息即时上屏（事件携带完整消息对象）。

安装包随附核心引擎、终端组件及 Ubuntu 24.04 ARM64 运行环境。升级安装保留应用数据。
