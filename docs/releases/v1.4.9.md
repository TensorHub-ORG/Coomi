# v1.4.9 更新说明【稳定】

2026-10-08 发布 · Android 7.0+ · ARM64

- 修复控制台设置分组嵌套错误和布局错位，恢复清晰的卡片、入口与导航。
- 新会话快捷指令默认收起为极简箭头，展开宽度限制为 280px；展开和收起时品牌标记、文案与指令列表平滑过渡，支持连续点击和系统减少动画设置。
- 完整恢复 1.4.8 辅助对话链路：新建、切换、归档、独立模型、工具执行、授权、问题回答及文件导入导出；修复刷新后丢失主从关联，并保持主会话模型、权限和上下文独立。
- 辅助助手可按需只读访问所属主对话，保留对其他会话和私有目录的隔离；关闭卡片后任务继续运行。
- 极简会话界面默认开启，用户可在设置中关闭，显式选择会继续保留。
- 会话设置整理为“对话、连接、应用”，找回默认工具权限、超载模型、极简界面和连接重试等选项。
- 修复工具调用显示 unknown 并误报参数校验失败的问题，兼容无索引流式工具片段、Responses 标识别名、旧式函数调用及无末尾换行的事件，避免调用被错误拆分。
- 延续新版引擎、工作室和协同工作台底座，完善手机返回链路、任务状态、快捷工具和附件体验。

安装包随附核心引擎、终端组件及 Ubuntu 24.04 ARM64 运行环境。升级安装保留应用数据。
