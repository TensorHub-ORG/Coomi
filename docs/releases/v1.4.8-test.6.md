# v1.4.8-test.6 更新说明【测试】

版本码：72；平台：Android 7.0+；架构：arm64-v8a。

- 优化三层扇形工具区：统一浅色底板和圆角按钮，移除厚重分割边框，使用清晰短标签，修复窄屏及放大字体时图标文字裁切。
- 移除会话内搜索悬浮按钮，保留键盘搜索快捷键。
- 修复流式输出闪烁：增量更新消息 DOM，避免已显示文本被重复替换，取消虚拟列表复用时重复播放的入场动画；同时修复代码块闭合、列表及引用链接显示。
- 核心引擎、终端引导和 Ubuntu 镜像完整内置，Android 初始化使用本地内置包；新增构建及 APK 内容校验，启动时检查并从内置资源修复损坏的缓存。
- 修复启动命令超时失效、登录脚本干扰内部启动和重启时跳过环境初始化的问题，保留用户自定义 shell 配置。
- Ubuntu 候选环境通过运行检查后才切换为就绪，安装失败或中断可恢复已有环境；重新部署保留旧环境及自定义软件，修复首次安装 DNS 初始化。
- 增加保留同一包名与签名的回退包构建参数。Android 不允许已有低版本码 APK 直接覆盖高版本；需要将稳定旧代码重打包为更高安装版本码，数据兼容性仍需验证。

验证范围：浏览器多尺寸与流式渲染回归、Java 启动和缓存修复回归、Rust 离线安装与恢复回归、签名 APK 及内置资源完整性校验。不同品牌真机的首次初始化和覆盖升级体验仍需测试反馈。
