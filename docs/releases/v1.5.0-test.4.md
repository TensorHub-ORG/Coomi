# v1.5.0-test.4 更新说明【测试】

发布日期：2026-10-19。Android 7.0+，仅 ARM64。构建号：94。

本版本通过测试通道发布，包含实验性改动，可能存在不稳定情况。

## 会话与运行可靠性

- 启动时可修复缺失的部署标记和过期引擎软链，通过健康检查后再进入运行状态；失败时提供日志信息。
- 精确识别并清理本应用的残留引擎，保留原有会话和运行环境。
- 修复切换会话、后台返回和断线重连后的记录缺失、重复与闪动，主会话和辅助会话均可恢复运行过程。
- 模型等待与只读工具允许并行，内置修改型工具通过互斥执行保护共享工作区。

## 思考与执行过程

- 思考随会话保存，重进会话可查看；正常停止和请求失败会保留已收到的部分思考，并标注中断或未完成状态。
- 自动重试、图片降级和超窗恢复会清理失败尝试，避免思考和文字串段；保存的思考仅用于展示。
- 同一轮的思考、工具和中间回复合并为执行过程，运行时展开，结束后默认折叠；最终回答、待审批工具和用户提问保持可见。
- 思考运行时显示约 3.5 行预览，完成状态由事件驱动，支持手动展开全文。
- 压缩完成后立即展示摘要；重连时按摘要标识去重，历史中仍能查看摘要与完整会话。

## 上下文与界面

- 新增固定分类颜色的上下文分段环和统计面板，区分窗口占用、估算组成和会话累计 Token，修正轮次耗时与输出速度的计时。
- 较早的超长工具输出在模型请求中保留首尾，完整会话记录与最近一条工具结果继续保留；图片与结构化内容单独处理。
- 新增黑白终端主题和等宽字体，覆盖聊天与原生界面，兼容已有自定义外观。
- 保留模式面板及消息入场动效，统一遵循“关闭所有动画”与系统减少动态效果设置。
- 新增更新提醒总开关，手动检查始终可用；测试版默认查看测试通道，下载前明确提示测试性质。
- 更新说明支持 Markdown 和普通版本标题，默认只展示最新记录，历史记录点击展开。

## 使用说明

- 本次仅更新测试渠道，不替换正式版下载。
- 版本名沿用 1.5.0-test.4，构建号升至 94，已安装较早构建的用户可覆盖升级。
- 长时间运行的交互 shell 会持有修改互斥锁；外部终端和 Shizuku 进程不在内置工具锁的保护范围内。
