# v1.4.8-test.4 更新说明【测试】

版本码：70；平台：Android 7.0+；架构：arm64-v8a。

- 输入框底部按钮按容器宽度整体缩放，字体、图标、加号和发送保持单行；会话模式名称统一为“普通 / 协同”。
- 上下文用量圆环新增四分之一环形快捷工具带，包含版本工具、常用提示词、辅助会话与小窗聊天。工具卡片采用统一的右上角圆形缺口布局；点击外部关闭卡片，点击圆环叉号收起工具带；小窗状态自动隐藏入口。
- Git 面板采用简洁状态行和列表布局；修复数据工具图表样式误覆盖页头导致返回按钮消失的问题。Git、还原、诊断与数据工具可在卡片内操作。
- 常用提示词支持内置指令、自定义名称、分类标签、编辑、删除与填入输入框。控制台“会话与体验”新增管理入口；提示词保存在引擎文件中，支持重启后恢复。
- 辅助会话拥有独立模型、上下文、工具调用、审批和提问；按需读取主会话记录，关闭卡片后继续执行，并作为子会话归档。修复异步切换、文件传输回调和提示词保存竞争造成的串会话或数据覆盖风险。
- OpenCode 区分 Zen / Go 配置，按模型匹配 Chat Completions、Responses、Anthropic 或 Gemini 协议，修复部分模型无法调用的问题。

验证：前端 17 项测试、浏览器窄屏与卡片交互检查、相关 Rust 持久化/隔离/协议测试，以及 Android 原生与 ARM64 编译通过。OpenCode 已完成本地协议验证，未使用真实订阅联调；真机交互仍需测试反馈。
