# v1.5.0-test.1 更新说明【测试】

- 全面修复 Agent 上下文管理：移除完整会话历史的重复注入，手动压缩不再将私人会话写入项目持久记忆，旧版自动生成的会话记忆不再自动加载。
- 会话设置新增自动上下文压缩百分比阈值，默认 80%，可自定义 10–95%；接近模型容量上限时提前保护。
- 重构手动 /compact：长历史按顺序分段总结、保留完整存档，空摘要或压缩失败时保留原历史；远程压缩接口不支持时切换本地摘要，界面显示压缩进度。
- 修复压缩后重新打开会话遗漏后续消息的问题，完整历史与压缩后的新消息合并展示并去重。
- 每个工具完成后立即保存结果，检查点写入失败时停止任务；未确认结果的中断操作明确标记为结果未知，恢复前检查实际状态，降低重复执行风险。
- 修复父任务结束或取消后子 Agent 继续运行的问题，同步取消子任务并清理其工具进程，不影响其他会话；修复子任务立即失败时状态残留和并发输出缺字。
- 子 Agent 与笔记读取权限随当前会话及追加用户消息同步，修复继承过期上下文和笔记授权不更新的问题；子 Agent 并发数遵循设置。
- 修复工具执行后 Hook 报错导致成功操作被误报为失败的问题；含修改操作的工具批次串行执行，避免路径别名或目录关系造成读写冲突。
- 收紧文本 XML 工具调用识别，只接受独立的调用封装，普通回答、引用和代码示例不再自动触发工具执行。

这是测试版本，建议先备份重要数据。测试版与正式版下载入口独立，应用内更新页面会明确标注测试通道。
