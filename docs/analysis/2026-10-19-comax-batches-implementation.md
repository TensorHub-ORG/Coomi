# Comax 高价值功能接入记录

对应 Coomi Android `1.5.0-test.4` / versionCode `94`。社区参考固定为 `maxtwin114514/comax@dbce1acbf6f8efbc69596826391811ff8a7d416a`，具体判断与源码链接见 [接入分析](2026-10-18-comax-integration-analysis.md)。沿用原仓库及社区文件的许可证与署名，以功能补丁接入。

## 本次实现

第一批保留启动自修复、精确残留进程识别、健康检查、日志轮转、会话视图快照与水位恢复，以及共享工作区工具门禁。第二批新增消息级展示思考、每次请求独立缓冲、成功/失败/取消状态、事件驱动结束、按用户轮次聚合过程、压缩摘要与 ID 去重。第三批补齐分类上下文环、统计计时、请求副本的工具首尾裁剪、黑白终端主题、更新提醒偏好和减少动效支持。

用户原有 Provider 兼容、Skill 路由降级和 Composer 滚动修复保留，并随本次源码发布；本次没有覆盖其实现。

## 语义与边界

- 思考字段使用 serde 默认值兼容旧会话。每次尝试最多保存 512 KiB，重试丢弃旧尝试；普通错误标为 failed，任务 abort 在 RAII guard 中同步落盘 interrupted。取消接口等待 guard 结束再发布结束事件。
- 成功消息与正常取消可跨引擎重启恢复；进程被直接杀死前尚未到达保存边界的流式片段不保证保留。取消落盘失败通过错误事件报告。
- 展示思考从常规模型请求和压缩请求中剥离；空的部分思考消息不作为 assistant 历史重放。原始存档继续保留。
- 过程块以用户轮次 ID 为界；最终回复、通知、问题与等待审批的工具留在外部，辅助会话使用自身运行状态。虚拟列表块复用稳定引用。
- 压缩先完成持久检查点，再发含 summary_id / summary 的完成事件；历史摘要用同一 ID 去重。
- 分类是估算组成，环按已用 / 窗口容量分配，无最小弧放大。技能描述从系统提示估算中扣除，消息部分随当前上下文估计调整，不作为精确计费。
- 较早的纯文本工具结果按窗口预算保留首尾，最新结果、图片和结构化 provider 项不处理；只改模型请求副本，不改磁盘结果，不移除紧急超窗保护。
- 原生主题、Web 主题与自定义外观优先级保持一致。终端字体使用系统 monospace，中文由设备字形回退决定。
- 测试构建默认打开测试通道及测试红点；提醒可独立关闭，手动检查保留，安装测试版有原生确认。
- 长交互 shell 持有修改门禁直到进程结束；外部终端和 Shizuku 不受该门禁约束。
- 云端远程访问、默认助手和电源键接管仍为独立专项。

- Rust engine：72 项通过，包括重试隔离、错误状态、实际 abort 后从 SessionStore 重载，以及中文首尾裁剪。
- Rust UI：67 项通过；Rust services：151 项通过、1 项现有忽略。
- Web：31 项通过，生产构建与类型检查通过。
- 生产 Web 的 Chromium 手机视口验证：320 / 390 / 430，无页面异常；过程折叠、最终回复、持久思考、暂停超过 900 ms 后仍运行、3.5 行预览、减少动效、终端对比度、测试通道默认值、提醒偏好和更新历史折叠均已检查。
- 第一批曾做 USB 真机安装与恢复验证；本轮按用户要求不连接 USB。新增原生界面的设备运行行为尚未做本轮真机验证。
- 发布脚本限定 Android 测试下载链接，保护同页桌面端下载；更新元数据使用版本单调检查、上传哈希校验、发布锁、原子替换与失败回滚。
- 官网源码以发布前线上页面为基准，保留现有桌面端内容与正式下载。此发布是 APK 与静态更新元数据，无数据库结构变更。
