## 卡顿修复

1. **原生事件线程阻塞**：真实桌面使用 IPC 兜底传输。原有同步 `engine_http` 会在窗口事件线程进行 TCP 读写，单次读取可等待 30 秒；空闲轮询同样走这条路径。改为 async 命令并使用 `spawn_blocking`，保持 API 不变。新增慢响应测试验证等待网络时命令执行线程仍可处理定时器。
2. **隐藏内容大量挂载**：折叠历史过程首次仅挂摘要；工具列表和工具行详情按展开状态挂载，减少隐藏 DOM 与解析开销。
3. **流式反复解析**：流式 Markdown 保持纯文本，结束后恢复富文本；避免出现表格后每个片段都重新解析全文。Markdown 与历史消息优化 memo 比较。
4. **空闲状态刷新**：会话轮询保留未变化的行和数组引用，避免每 5 秒重复刷新；用 ID 集合消除列表查找的平方复杂度，运行状态变化仍立即生效。
5. **后台任务与观察器**：插件热加载禁止请求重叠，窗口隐藏时暂停检查；清除插件 mascot 时断开全局观察器；设置页只挂载当前分组。
6. **诊断**：既有 10 秒状态上报增加长任务、DOM 数及活动动画统计，不增加轮询或持续动画帧。开发壳日志可查看状态；启动恢复成功后清除对应旧错误。
7. **渲染风暴误判**：按实际渲染耗时与连续昂贵窗口判断，正常帧率和一次性挂载不触发降级；通知使用固定标识，避免反复弹出。性能回归确认未进入安全模式。
8. **连接隔离与恢复**：WebSocket 打开、发送和关闭移入异步工作线程；IPC 顺序发送，连接身份隔离旧事件，取消中的握手不会覆盖新连接。真实空闲引擎退出后自动恢复耗时 6,874ms，健康接口及前端连接均恢复。
9. **隐私说明默认状态**：说明链接不再自动聚焦，确认框默认不勾选；阻塞式引导重新展示时重置确认状态，保留正常键盘导航。
