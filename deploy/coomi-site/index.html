v1.2.2 更新说明【稳定】

2026-08-03 发布

  • 切换会话不中断：切换会话时任务在后台继续执行，会话列表显示运行中状态；断线审批缓存，重连自动补发。
  • 草稿按会话独立保存：每个会话（含新会话）输入框内容独立持久化，互不串用。
  • 会话排序修正：按最后一轮执行时间排序，点击会话不再刷新排序时间。
  • 图片崩溃修复：无图像理解能力的模型自动过滤图片消息，不再 400 报错、不再整会话失效。
  • 主题三档切换：跟随系统 / 明亮 / 夜间，对话界面、控制台、引导页全链路统一暗色，原生状态栏联动。
  • SKILL / MCP 管理完善：管理面板停用（文件保留可恢复）、彻底删除；AI 自行卸载为物理删除。
  • 引擎单实例锁：防止多引擎实例并发导致会话串扰。
  • 手机存储访问开关：默认关闭，开启后联动系统授权，Agent 可读取真实手机目录。
  • 图片展示增强：新增 show_image 工具，大图卡片展示、点击全屏预览、保存到相册或下载目录；工具卡片瀑布流渲染。
  • 图像理解修复：provider 新增「支持图像理解」开关；OpenAI 兼容 image_url 格式真实上传图片；识别失败自动降级，不再崩会话。
  • 上下文压缩修复：图片按固定 token 估算，不再因图片误触发压缩；压缩后本地缓存完整历史可回溯；长会话窗口化渲染、上滑动态加载。
  • 大文件分段读取：read_file 默认只读前 64 KiB，支持 offset 分批继续读取；超长单行自动截断。
  • 问询窗口优化：去头像自然排版，右上角新增「跳过」按钮，跳过时回复记为空。
  • 界面统一：控制台入口返回动画与系统一致；引导页明暗主题适配；provider 保存 / 检索模型流程修复。
  • Agent 感知已装 MCP：系统提示注入已配置 MCP 清单，Agent 可直接调用。

v1.2.1 更新说明

2026-08-02 发布

  • 修复引擎无法启动：升级后引擎无法启动的问题已修复，打开应用即可正常进入。
  • 启动流程优化：重新打开应用先进控制台（引擎状态一目了然），再从控制台进入对话。
  • 文件管理：控制台新增「文件管理」独立入口，支持新建、重命名、删除、复制、粘贴、复制路径、打开等操作。
  • SKILL / MCP 管理重做：卡片式布局，安装需二次确认，支持卸载；Skill 安装改为在线下载，不再依赖 git 环境。
  • 全局会话记忆：新增开关（默认关闭），开启后 Coomi 可读取所有历史会话文件；关闭时引擎强制屏蔽会话记录目录，严格隔离隐私。历史会话列表始终可见、记录持续保留。
  • 上下文修复：报错或中断后同一会话继续对话，Coomi 仍能读取上文。
  • 权限提示优化：访问无权限目录时明确提示「禁止访问」。
  • 界面修复：修复对话界面右侧显示不全、点击蓝色闪光等问题；引擎状态显示「启动中 / 运行中 / 未启动」三态。

v1.2.0 更新说明

2026-08-02 发布

  • 修复引擎启动：修复升级后引擎无法启动的问题，打开应用即可正常进入。
  • 启动流程优化：重新打开应用时先进控制台（引擎状态一目了然），再从控制台进入对话，符合日常使用习惯。
  • 文件管理：控制台新增「文件管理」独立入口，支持新建、重命名、删除、复制、粘贴、复制路径、打开等完整文件操作。
  • SKILL / MCP 管理重做：卡片式布局，信息一目了然；安装前必须确认，不再误触即装。
  • 权限提示优化：访问无权限目录时明确提示「禁止访问」，不再显示莫名的加载错误。
  • 会话管理增强：删除/清空会话会同步清理引擎记录，历史会话不再「删不掉、又复活」；删除前增加二次确认。
  • 界面修复：修复对话界面右侧显示不全、文件管理列表无法滚动等显示问题，整体布局更整齐。

v1.1.0 更新说明

2026-08-02 发布

  • 独立包名：应用包名改为 com.coomi.android，与官方 Termux 彻底分离，可同时安装互不干扰。
  • 联网搜索修复：web_search 改用稳定端点（Bing RSS）并内置 fetch 网页抓取工具，联网能力开箱即用。
  • 会话隔离：修复会话错乱问题，同一会话只读取本会话的历史与项目上下文，不再跨会话串台。
  • 停止按钮：点击停止可真正终止正在执行的工具与 shell 进程，界面即时反馈「已取消」状态。
  • 安全加固：fetch 增加 SSRF 防护与读取上限，本地服务收紧跨域访问，防止 API Key 泄露。
