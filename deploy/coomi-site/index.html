Features

官方能力全在，另外还有这些

标着「魔改」的是这一版新增或重做的部分。

魔改超载模式（注意力全开）

产能模式升级为「超载」。模型先定义问题、限制条件、成功标准与失败边界，再动手；所有关键事实必须通过工具或原始资料交叉验证；零冗余输出，每一句都承载信息量。

魔改控制模式

无障碍 + 桌面悬浮球，代替你点击、输入、发送。

魔改AI 工作室

多成员协同、群聊 @ 调度、工单看板与审批流。

魔改Operit 工具集成

内置 local_model、local_ocr、local_tts、ui_automation 四个本地工具。

UB官方完整 Ubuntu 24.04

内嵌 ProotLinux + Ubuntu 24.04 LTS，C/C++ 构建链、sqlite3、网络工具开箱即用。

DS官方DeepSeek 账号登录

密码 / 验证码双通道，复用 DeepSeek App 订阅额度，无需单独购买 API 额度。

SK官方Skill / MCP 扩展

技能市场与 MCP 配置热更新，内置 UI 设计师、环境模板、skill-creator 等技能。

IO官方记录导入导出

JSON / JSONL / Markdown / TXT 全格式导入导出，导入前可预览。

1.5.0o3 更新说明

控制模式重做

新增主动申请无障碍权限；桌面悬浮层显示正在调用的工具与思考过程，不用时可拖动缩成小球。

适配新版会话 ID 与模型类型，修复登录后无法发起会话；账号接口统一节流与串行，持久化设备标识。
